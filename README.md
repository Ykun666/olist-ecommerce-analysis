# Olist电商用户行为分析

## 项目背景

本项目旨在通过对 Olist 电商历史订单数据进行系统分析，识别影响用户体验与业务增长的关键因素，并输出可执行的业务优化建议。  
数据集来源为 Kaggle 公共数据集 Olist Brazilian E-Commerce。

## 主要发现

1. 配送时长是差评核心驱动因素（超15天差评率从5%升至20%+）
2. 复购率约3%，平台以新客为主
3. 高价值用户占6.9%，平均消费是普通用户2.8倍
4. 11月黑五订单峰值明显

## 业务建议

1. 针对长尾订单建立履约预警机制，对预计超时订单提前触达用户并提供补偿方案，优先降低“超15天”订单占比。
2. 围绕首单用户设计30天复购激励路径（优惠券、二次推荐、触达提醒），提升新客转化为复购用户的比例。
3. 面向高价值用户建立分层运营策略（专属客服、优先履约、会员权益），提高高价值用户留存和贡献稳定性。
4. 在黑五等峰值周期提前做好库存、仓配与客服容量规划，减少高峰期履约波动和体验下降。

## 项目结构

- `notebooks/01_数据清洗.ipynb`：多表字段清洗、主键关联校验、数据口径统一  
- `notebooks/02_EDA探索分析.ipynb`：订单、支付、履约时效与评价分布探索  
- `notebooks/03_用户分层.ipynb`：复购与消费行为分析、用户价值分层  
- `notebooks/04_结论与建议.ipynb`：汇总结论并输出业务建议
